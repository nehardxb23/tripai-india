### 🌍 Overview

Planning a trip can be overwhelming. Travelers often spend hours researching destinations, attractions, transportation, food, and budgeting.

**TripAI India** simplifies this process by generating a personalized travel itinerary in seconds using AI.

Users simply enter:

- 📍 Destination
- 📅 Number of Days
- 💰 Budget Per Day
- 🎒 Travel Style

The application creates a complete travel plan including attractions, hidden gems, food recommendations, transport suggestions, maps, packing tips, and a budget breakdown.

### 🚀 How It Works

1️⃣ Enter your destination.

2️⃣ Choose travel days.

3️⃣ Select budget.

4️⃣ Pick travel style.

5️⃣ AI generates a personalized itinerary.

6️⃣ Explore interactive maps and travel recommendations.

7️⃣ Download your itinerary as a PDF.
